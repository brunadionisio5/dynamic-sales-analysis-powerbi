# Dynamic Sales Analysis - Power BI

## Sobre o projeto

Este projeto explora a criação de dashboards dinâmicos no Power BI utilizando **parâmetros de campos**, permitindo que o usuário altere a visualização dos dados de forma interativa.

---

## Objetivo

Demonstrar como parâmetros podem tornar a análise mais flexível e personalizada, melhorando a experiência do usuário.

---

## Funcionalidades

- Alternância de categorias (ex: produto, segmento, região)
- Alternância de métricas (ex: vendas, lucro)
- Visuais dinâmicos controlados pelo usuário
- Navegação intuitiva

---

## Estrutura

Página adicional criada com foco em apresentação para cliente, contendo:

- Título explicativo
- Visuais organizados
- Elementos interativos
- Narrativa orientando a análise

---

## Como executar

1. Abra o arquivo `.pbix` no Power BI Desktop
2. Utilize os seletores de parâmetros para alterar as visualizações
